# Superseded specs

These OpenAPI documents were **derived from the FirstPromoter documentation pages** in an earlier
enrichment round, before the provider's own published OpenAPI files were located.

On 2026-08-13 the pipeline found FirstPromoter's real, first-party OpenAPI documents indexed in
<https://docs.firstpromoter.com/llms.txt> under `## OpenAPI Specs` and harvested 37 of them
(179 operations) verbatim into `openapi/_original/` and `openapi/`.

Every path in the superseded documents is covered by the published specs, so these files are kept
only for provenance and are no longer referenced from `apis.yml`.
